# Audit du 31 août 2026 — intégration des six programmes officiels Oracle

Cet audit fait suite à [AUDIT-2026-08-30.md](./AUDIT-2026-08-30.md). Il porte sur
l'intégration **des sujets d'examen officiels des six certifications**, sur
l'extension des cursus aux domaines qui n'étaient pas couverts, et sur
l'introduction des schémas explicatifs dans les cours.

Toutes les mesures ci-dessous sont produites par exécution réelle du code.

---

libellés de cours vivent dans `lib/exam-sources.ts` — un module dédié, pour
éviter le cycle d'import que la première version avait introduit.

## 4. Les schémas dans les cours

Un type de bloc `figure` a été ajouté au modèle de contenu
(`lib/course-oca-sql.ts`) et à son rendu (`components/course-blocks.tsx`).
Chaque schéma porte un texte alternatif bilingue pour les lecteurs d'écran et
une légende qui dit **ce qu'il faut y voir**, plutôt que de décrire l'image.

| Cursus | Schéma | Ce qu'il montre |
|---|---|---|
| 1Z0-071 | `oracle-erd.svg` | Correspondance entre les clauses d'un SELECT et un diagramme entité-association |
| 1Z0-082 | `oracle-instance.svg` | Séparation instance / base : SGA et processus d'un côté, fichiers de l'autre |
| 1Z0-082 | `oracle-security-privileges.svg` | Propagation des privilèges système, objet et des rôles |
| 1Z0-083 | `oracle-backup-rman.svg` | Cycle complet de sauvegarde et de restauration RMAN |
| 1Z0-084 | `oracle-tuning-awr.svg` | Répartition du DB time par classe d'attente, puis la chaîne AWR → ASH → ADDM → conseillers |
| 1Z0-084 | `oracle-row-chaining.svg` | **Nouveau** — chaînage contre migration, côte à côte |
| 1Z0-084 | `oracle-rat-flow.svg` | **Nouveau** — chaîne SPA et Database Replay, du SQL Tuning Set au rapport de divergences |
| 1Z0-076 | `oracle-dataguard.svg` | Principale, Far Sync et secours, avec les trois modes de protection |
| 1Z0-078 | `oracle-rac-cluster.svg` | Deux instances, Cache Fusion, ASM partagé sous un SCAN unique |
| 1Z0-078 | `oracle-flex-asm.svg` | **Nouveau** — ASM classique contre Flex ASM, et l'effet d'une panne d'instance ASM |
